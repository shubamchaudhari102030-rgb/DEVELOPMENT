// ======================================== // EVENTS & EVENT LISTENERS // ======================================== // Event: // An event is an action that happens on a webpage. // Example: click, keypress, mouseover, submit, etc. // Event Listener: // An event listener waits for a specific event // and runs a function when that event occurs. // Syntax: // element.addEventListener("event", function); // Example: // button.addEventListener("click", changeText); // Here: // "click" -> Event // changeText -> Function executed when event occurs // In short: // Event = Action // Event Listener = Watches/handles that action
